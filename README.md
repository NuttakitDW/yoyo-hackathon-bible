# 🧑‍🚀 Yoyo Hackathon Guideline Bible

![Made with ❤️](https://img.shields.io/badge/made%20with-%E2%9D%A4-red)

A **step‑by‑step framework** for validating and shipping hackathon ideas, inspired by Yoyo’s battle‑tested method.  
Use it to avoid random pivots, focus on judge‑friendly problems, and ship polished end‑user apps—especially when playing with ZK/Noir stacks.

> *“Think hard each step—don’t rely on luck.” — Yoyo*

## 🚀 Quick Start

```bash
# clone the repo
git clone https://github.com/<your‑org>/yoyo-hackathon-bible.git
cd yoyo-hackathon-bible
```

1. **Duplicate the template**

   Make a copy of `yoyo_hackathon_guideline_bible.md` (or import it into Notion—see below).  
   Rename the file/folder to match your hackathon.

2. **Fill in the blanks**

   The template is divided into ten focused sections:

   | Section | Outcome |
   |---------|---------|
   | **0 Context Snapshot** | Hard facts (dates, judges, tech mandates) |
   | **1 Problem Hunt** | Raw list of host‑aligned pain points |
   | **2 Idea Scoring Matrix** | Quantitative tier list (S/A/B/C) |
   | **3 Pick the Winner** | Primary & fallback idea |
   | **4 Spec Blueprint** | One‑pager product spec |
   | **5 Technical Architecture** | High‑level system sketch |
   | **6 Rapid Validation** | User & judge feedback |
   | **7 Build Plan** | Hour‑by‑hour task board |
   | **8 Demo Narrative** | 5‑minute pitch outline |
   | **9 Fallback & Post‑Hack** | Plan B + go‑to‑market notes |

3. **Run your sprint**  
   Use the checkboxes/tables to track progress. Move fast, but stay intentional.

---

## 📚 Importing into Notion

1. Open Notion → **Import** → **Markdown & CSV**.  
2. Paste the entire contents of `yoyo_hackathon_guideline_bible.md`.  
3. Convert any markdown tables to Notion databases for kanban or calendar views.  
4. Duplicate the page for every new hackathon.
